# system_design_note

Summary notes for *System Design Interview* by Alex Xu, written as HTML pages that use tables and Mermaid diagrams.

## How to read

- **Locally:** open `index.html` in a browser. The diagrams load Mermaid from a CDN, so you need an internet connection.
- **Online:** turn on GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`) and open the published site.
