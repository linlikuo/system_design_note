Ch 2 — Back-of-the-Envelope Estimation

System Design Interview by Alex Xu. Summary notes.

Overview

Back-of-the-envelope estimation means quick, rough calculations (QPS, storage, and so on) that show whether a design can handle the load. The goal is the right order of magnitude, not an exact number.

Performance rules of thumb

FactWhat to do
Memory is fast, disk is slowKeep hot data in memory (cache)
Disk seeks are slowAvoid disk seeks when possible
Simple compression algorithms are fastCompressing is cheap, so it's usually worth it
Sending data over the internet takes timeCompress data before sending it
Data centers are usually in different regionsSending data between DCs is slow, so keep cross-region calls to a minimum

Tips

Commonly asked estimations

QPS

Queries per second on average.

Peak QPS

The busiest-time load that capacity has to handle.

Storage

How much data builds up over the retention period.

Cache

How much memory is needed to hold hot data.

Number of servers

How many machines are needed to serve the load.
